# คู่มือการใช้งาน NomiFun Desktop (ฉบับภาษาไทย)

ยินดีต้อนรับสู่ **NomiFun Desktop** ซูเปอร์ AI Workstation แบบโอเพนซอร์สที่ทำงานแบบ Local-first ข้อมูลทั้งหมดอยู่บนเครื่องของคุณ 100%

---

## 1. วิธีเปิดใช้งานโปรแกรม
- **วิธีที่ 1**: ดับเบิลคลิกที่ไอคอน `NomiFun Desktop` บนหน้าจอ Desktop ของคุณ
- **วิธีที่ 2**: ดับเบิลคลิกไฟล์ `run-nomifun.bat` หรือ `nomifun-desktop.exe` ในโฟลเดอร์นี้

---

## 2. การจัดการโมเดล AI (Model Management)
- **โมเดลฟรีที่มาพร้อมโปรแกรม (Free Models)**:
  - ระบบมีโมเดลฟรีในตัว เช่น `big-pickle`, `deepseek-v4-flash-free`, `mimo-v2.6-flash-free` พร้อมใช้งานทันทีโดยไม่ต้องใส่ API Key
- **การเชื่อมต่อ Local LLM (Ollama)**:
  - ติดตั้งและเปิด Ollama ในเครื่อง (`http://127.0.0.1:11434`)
  - NomiFun ได้รับการตั้งค่าเชื่อมต่อกับ Ollama ไว้ล่วงหน้า สามารถเลือกใช้โมเดลออฟไลน์ได้ทันที
- **การเชื่อมต่อ Cloud Providers**:
  - ไปที่เมนู **การตั้งค่า (Settings) > ผู้ให้บริการโมเดล (Providers)**
  - เลือกผู้ให้บริการ เช่น OpenAI, Anthropic (Claude), Google Gemini, DeepSeek, OpenRouter หรือ Custom Gateway แล้วใส่ API Key

---

## 3. พรีเซ็ตผู้ช่วยภาษาไทย (Thai Presets)
ระบบได้ติดตั้งพรีเซ็ตพร้อมใช้งาน 4 รูปแบบ:
1. **โปรแกรมเมอร์คู่คิด (Thai Coding Partner)**: เชี่ยวชาญการเขียนโค้ด ตรวจสอบบั๊ก และแนะนำสถาปัตยกรรม
2. **วิเคราะห์เอกสารและข้อมูล (Data & Doc Analyst)**: สรุปเอกสาร PDF, ข้อมูลสถิติ, Excel และรายงานธุรกิจ
3. **นักเขียนคอนเทนต์และการตลาด (Content Creator)**: ร่างบทความ โพสต์โซเชียลมีเดีย สคริปต์ และงานการตลาด
4. **ผู้ช่วยสำนักงานอัจฉริยะ (Smart Office Assistant)**: ช่วยร่างอีเมล บันทึกการประชุม และงานธุรการ

*สามารถเลือกพรีเซ็ตได้ทันทีจากเมนูเลือกพรีเซ็ตก่อนเริ่มแชต*

---

## 4. เพื่อนคู่คิดบนเดสก์ท็อป (Desktop Companion)
- **น้องโนมิ (Nomi)**: Companion สไตล์ `mochi` ที่พร้อมช่วยเหลือและเรียนรู้สไตล์การทำงานของคุณ
- สามารถตั้งค่าให้ลอยอยู่บนหน้าจอเดสก์ท็อป (Stay on top) ขณะทำงานในโปรแกรมอื่นได้
- มีระบบความจำระยะยาว (Long-term Memory) คอยจดจำบริบทและโปรเจกต์ของคุณ

---

## 5. การทำงานอัตโนมัติ (Browser-Use & Scheduled Tasks)
- **Browser-Use**: สั่งให้ Agent เข้าเว็บไซต์ หาข้อมูล หรือกรอกฟอร์มได้อัตโนมัติผ่านเบราว์เซอร์ในเครื่อง
- **งานตั้งเวลา (Cron Tasks)**: ตั้งเวลารันงานอัตโนมัติ เช่น สรุปข่าวประจำวันเวลา 08:00 น. ผ่านเมนู Scheduled Tasks
